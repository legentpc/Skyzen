# Features

## Hunting

* **Line to Floor Drop** — Draws a line to the nearest floor drop on the ground. The line switches to the next drop when one is collected. Works in Moonglade Marsh, Torrhus Canyon, and Critter Safari.
  Options: *Hunting → Line to Floor Drop* (default: ON), *Line Width* (default: 3), *Floor Drop Islands* (default: all three), *Maximum Distance* (default: 15), *Scan Radius* (default: 20)

## Misc

* **Gift Clean Display** — Hides the `From:` / `To:` nametags floating above gift entities in SkyBlock.
  Toggle: *Misc → Clean Gift Nametags* (default: ON)

## General

* **Config GUI** — Type `/skyzen` in chat to open the settings menu, powered by Lattice.
