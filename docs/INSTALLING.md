# Download and Install Skyzen

Skyzen is a client-side Fabric mod for the Minecraft versions currently supported by Hypixel SkyBlock.

## Requirements

* Minecraft Java Edition (a version supported by Hypixel SkyBlock)
* [Fabric Loader](https://fabricmc.net/use/)
* [Fabric API](https://modrinth.com/mod/fabric-api)
* [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)

## Installation

1. Download the latest `skyzen-<version>.jar` from the [releases page](https://github.com/LegentPc/Skyzen/releases).
2. Place the jar in your `.minecraft/mods` folder, together with Fabric API and Fabric Language Kotlin.
3. Launch the game with your Fabric profile.
4. Type `/skyzen` in chat to open the settings menu.

For Java performance tips, see [UPDATE_JAVA.md](UPDATE_JAVA.md).
